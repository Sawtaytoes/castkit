# Management navigation prioritizes views and displays

Status: Accepted
Date: 2026-10-07
Type: User preference
Supersedes: None
Superseded by: None

## Decision

Order management navigation as Views, Screens, Devices, Channels, Sources, Plugins, Access. All Views is a gallery mode within Views. Device overview is reached within Devices and highlights Devices in navigation; its existing URL remains supported.

## Context

The previous rail placed an overview, Sources, and Channels above the views and destinations people inspect most often.

## Why

Put frequent content and display tasks first while keeping the content gallery inside its parent section.

## Evidence

User request, chat `2111a4ce-1a8d-463e-a6a4-51623d26e077`, 2026-10-07:

> “Views (all views would be in here too, and you can filter down to only the views you wanna see), Screens/Devices, Channels, Sources, Plugins, Access.”

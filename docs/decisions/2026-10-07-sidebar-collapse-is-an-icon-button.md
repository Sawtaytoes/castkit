# Sidebar collapse is an icon button

Status: Accepted
Date: 2026-10-07
Type: User preference
Supersedes: None
Superseded by: None

## Decision

The management rail uses an accessible icon button to expand or collapse navigation. Its accessible label states the action.

## Context

The previous footer used visible Collapse/Expand text for an action already represented clearly by a navigation icon.

## Why

Keep the content library, output destinations, and local inspection controls understandable and inexpensive to use.

## Evidence

User request, chat `2111a4ce-1a8d-463e-a6a4-51623d26e077`, 2026-10-07:

> “I don't like using text where icons make more sense.”

# Storybook calls this view 3D Printer Status

- **Status:** Accepted
- **Date:** 2026-09-28
- **Type:** Storybook naming
- **Supersedes:** —
- **Superseded by:** —

## Decision

The browser Storybook title is `Views/3D Printer Status`. The product view and
Home Assistant option keep the name `Printer Status`.

## Context

The Storybook title `Views/Printer Status` could describe a paper printer. This
view is specific to 3D printers.

## Why

The Storybook name must identify the printer type. The panel and Home Assistant
names remain stable because their use is clear in that context.

# Queue chooser

The `queue-picker` view consumes `queue-picker.v1` from any configured source. A named MQTT channel can use QueuePilot's `queuepilot/chooser/<reader>/state` and send actions to `queuepilot/cmd/chooser/<reader>` with the allowlist `touch`, `choose`, `remove`, `reset`, `dismiss`.

The contract carries `sessionId`, `revision`, `isActive`, `expiresAt` (epoch milliseconds), selected `people: [{id,name}]`, and `queues: [{id,title}]`, plus an optional status `message`. A source owns audience matching and playback. CastKit never infers a person's identity or selects the first matching queue.

The view shows removable avatars, Reset, and Close in one compact header, followed by a vertically scrolling grid of square poster tiles. Six complete tiles fit on a 480 by 480 display. The entire square is tappable, and narrower panels reduce the column count. The native scroll region uses a session/revision identity and aligns to eight-row transport bands. Optional queue artworkPath values show a lineup sample from the source, with colored play tiles if artwork is missing or fails. Shuffled previews do not reserve the next playback item. Queue IDs determine their Charcuterie categorical colors, matching QueuePilot’s queue accents. Interactive controls use the source action path and carry the current session/revision. Expired data is non-actionable even when retained on the broker. Read-only panels cannot issue commands.

An interaction sends `touch` without a polling heartbeat; manual scroll gestures also send it. Automated state refreshes do not extend inactivity. The source should publish a new expiry and the installation should renew its existing temporary display override. Room edge swipes dismiss the source selection and clear only this view's override, letting the ordinary room controller resume. Existing override priority policy remains in the installation.

The header has no visible title or person names; accessible labels preserve each person’s identity and removal action. Status text appears only for idle, error, or source messages. The same contract renders on other sizes; delivery technology is not a branch in the view. The browser tests run in the four shared windows, and `Views/Queue chooser` supplies invented data for visual regression.

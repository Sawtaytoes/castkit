Your picks: B for Clock and Weather, A for Calendar with a horizontal header. Three things you asked to see: where the AM/PM sits on Clock B, the condition marks on Weather B, and two ways to lay the Calendar header out on one row. The marks are drawn in CastKit: Home Assistant sends only the condition code (sunny, rainy, …), and CastKit already turns that code into the text, so it can turn it into a mark the same way. Fifteen codes, fifteen marks, all shown at the bottom.
